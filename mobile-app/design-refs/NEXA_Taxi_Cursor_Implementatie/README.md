# NEXA Taxi Cursor package

1. Pak ZIP uit in de repository-root of in een tijdelijke map.
2. Open `NEXA_TAXI_CURSOR_IMPLEMENTATIE.md` in Cursor.
3. Geef Cursor de startopdracht uit hoofdstuk 0.
4. Laat Cursor eerst audit uitvoeren voordat migrations, SDK's of bestaande auth worden aangepast.
5. `assets/` bevat direct inzetbare SVG/PNG bestanden. `references/screens/` bevat zes visuele conceptschermen, geen kant-en-klare UI.
6. Twilio credentials, fysieke device-tests, VoIP push-config en deployment zijn nog nodig voor werkende in-app telefoongesprekken.

De taxi-afbeeldingen zijn AI-gegenereerde ontwerpassets; beoordeel merkgebruik voor productie.
