# NEXA TAXI — zes schermen + designimplementatie voor Cursor

Start met **`NEXA_TAXI_PIXEL_PRECISE_CURSOR.md`** en open daarna alle originele screenshots in `references/`.

- `references/` — de zes door de gebruiker aangeleverde PNG's (ongewijzigd, 941 × 1672 px).
- `assets/backgrounds/` — eigen vectorlagen voor decoratieve map/route/gradient, dark + light.
- `assets/icons/` — kleine, schaalbare SVG's voor implementatie (of vervang door bestaande Lucide icon set).
- `assets/crops/` — alleen uitgesneden **referentiebeelden** uit screenshots, dus **geen** vrijstaande transparante taxi's.
- `assets/tokens/` — ontwerp-/thema-tokens JSON.

**Beperking:** losse originele auto's, city photography en merklogo's kunnen niet betrouwbaar worden teruggewonnen uit een afgeplatte screenshot. Cursor moet echte bestaande assets uit de NEXA-repo gebruiken of ze als ontbrekend rapporteren. De screenshots bieden wel volledige, precieze visuele referentie voor de zes dark-mode schermen. De light-mode specificatie is afgeleid van dezelfde layout; er zijn bij deze beurt geen zes oorspronkelijke light-mode referenties aangeleverd.
